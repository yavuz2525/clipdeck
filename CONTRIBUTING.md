# Contributing to ClipDeck

Thanks for helping improve ClipDeck.

## Development

1. Fork and clone the repository.
2. Run `npm install`.
3. Create a focused branch.
4. Make your changes.
5. Run `npm run check && npm test`.
6. Open a pull request explaining the user-facing impact.

Please keep the project privacy-first: new network calls, telemetry, cloud storage or external services should be opt-in and clearly documented.
